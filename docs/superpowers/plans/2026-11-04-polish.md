# Polish pass — "plant control room" (2026-11-04)

Goal: the product must look designed by a studio for Thai factories, not generated, and every dashboard must have visualizations a buyer remembers. Read DESIGN.md (section "Direction: the plant control room") first — it is the brief.

## New shared pieces (use them; don't edit them)
- `InstrumentBand` (`@/components/data/instrument-band`) — the ONE bold element on a dashboard: 3–4 readings with sparkline + delta, optional `live` line. Put it right under the PageHeader on dashboards/overview pages only.
- `Sparkline`, `StatTile` now accepts `spark={number[]}`.
- `Heatmap` (`@/components/data/heatmap`) — rows × columns matrix (machine × day, hour × day…), sequential green ramp, null = hatched "no data".
- `Meter` and `Gauge` (`@/components/data/meter`) — value vs target, half-donut %.
- `ProportionBar` (`@/components/data/proportion-bar`) — part-to-whole (scopes, resource share). Never pie/donut charts.
- `Nameplate` (`@/components/data/nameplate`) — machine/checkpoint/QR/company codes. Replace every `font-mono` code with it.
- `font-display` utility = Bai Jamjuree (numbers, big values, page titles are already h1).
- Top bar context is now `{ primary, secondary }`. Dark mode works (ThemeToggle in top bar) — check your pages in dark too.

## Remove these generated-UI tells everywhere in your area
1. Meta strings joined by " · " or " • " → separate elements (muted text, line break, or a small dl). Dates/ranges: "28 ต.ค. – 3 พ.ย. 2569" is fine; joining unrelated facts with dots is not.
2. "WORD — fragment" labels (e.g. "ไฟฟ้า — พลังงานและสาธารณูปโภค") → primary text + muted secondary line/span.
3. Arrows appended to links/buttons ("ทั้งหมด →", "→" icons after text). Use plain words; an icon only if it means something (external link, download).
4. ALL-CAPS tracked eyebrow labels and small labels above every heading.
5. `font-mono` for codes → `Nameplate`. Keep mono only for raw tokens/URLs.
6. Card-in-card and grids of identical cards. A page = PageHeader, (InstrumentBand on dashboards), then panels sized by importance; inside a panel use divided lists/tables. Vary layout: wide main + narrow aside, full-width heatmap, etc.
7. Decorative motion. No entrance animations.
8. Copy: plain, specific, Thai sentence-case, verbs on buttons ("บันทึก", "สร้างผู้ใช้"), empty states say what to do next.
